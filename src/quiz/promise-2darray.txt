Yes, the flow of execution is different. The fetch() API is inherently asynchronous and non-blocking because it performs network requests. 
When we use fetch(), the request is sent, and the JavaScript engine continues executing the rest of the code without waiting for the response. 
Once the response is received, the Promise returned by fetch() is resolved or rejected, and the corresponding .then() or .catch() handlers are executed.
